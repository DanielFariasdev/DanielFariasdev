Olá, sou Daniel Farias — Desenvolvedor Backend 👋

## 🙋‍♂️ Sobre mim

Desenvolvedor backend de Salvador, Bahia, com foco na construção de APIs e aplicações web.

Tenho desenvolvido projetos práticos com JavaScript, TypeScript, Node.js e bancos de dados SQL. Também estudo tecnologias de front-end para entender e construir experiências completas, da interface à API.

Tenho interesse especial em:

- Desenvolvimento de APIs REST
- Node.js, Express e NestJS
- Modelagem e integração com bancos de dados SQL
- Autenticação e organização de aplicações
- Interfaces web responsivas com HTML, CSS e React
- Aprendizado contínuo por meio de projetos

Meu objetivo é evoluir como desenvolvedor backend e contribuir para aplicações úteis, bem estruturadas e fáceis de manter.
